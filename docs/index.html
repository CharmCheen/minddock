Architecture

系统架构分层

从数据接入到智能响应，四层架构清晰分离，各司其职

1

Ingestion Layer — 数据接入层

Source Skills 负责异构数据源的解析、清洗与向量化，统一输出 Chunk → Embedding → Metadata 三元组

PDF/MD/URL/CSVImage OCRAudio/Video Transcription
2

Retrieval Layer — 检索增强层

多策略检索（语义 + 关键词 + 混合），配合质量反思节点自动评估检索结果相关性，支持有界重试

Hybrid SearchReflection NodeBounded RetryReranking
3

Agent Layer — 智能编排层

基于 LangGraph 的实验性工作流编排，意图感知路由、source-scoped 对比规划、多轮对话上下文管理

LangGraphIntent RouterState MachineContext Window
4

Response Layer — 响应呈现层

渐进式 SSE Streaming 实时输出，支持引用溯源、结构化格式渲染、完整可观测性追踪

SSE StreamCitationObservabilityTracing
Workflow

执行流程

从用户查询到最终响应的轻量级 RAG 执行链路

1

Query Ingestion

接收用户输入，进行预处理与意图初步分析

2

Intent Classification

意图感知模块识别查询类型（事实性 / 分析性 / 创造性），路由至最优处理路径

3

Multi-Strategy Retrieval

并行执行语义检索与关键词检索，融合排序后输出候选文档集

4

Quality Reflection

反思节点评估检索质量，不满足阈值时触发有界重试机制优化检索策略

5

Source-Scoped Planning

基于检索到的来源范围进行对比规划，生成结构化回答框架

6

Progressive Streaming

渐进式 SSE 流式输出最终回答，实时呈现生成过程与引用标注

技术栈

精选现代 AI 工程技术栈，兼顾性能、可扩展性与开发者体验

Core Framework
  • FastAPI — 后端 API 服务

  • 本地运行日志与执行记录
Source & Media Processing
  • PyMuPDF PDF 文本解析

Open Source

开源共建

MindDock 坚信开放协作的力量。我们正在构建一个面向个人知识管理的开源生态系统。

作为一个开源项目，MindDock 欢迎每一位贡献者。无论是提交 Bug Fix、新增 Source Skill、改进检索算法，还是完善文档和示例，你的每一份参与都在推动项目向前发展。

内置 Source Skill Catalog

系统内置只读的 Source Skill Catalog，描述已实现的 7 种数据接入能力（PDF、Markdown、TXT、URL、CSV、图片 OCR、音视频转录）。每种 Skill 均有标准化的能力描述、Provider 列表与已知限制说明，便于后续扩展用户自定义 Skill。

透明的开发流程

所有设计决策、架构讨论、功能规划都在 GitHub Issues 和 Discussions 中公开进行。我们采用 RFC 驱动的提案机制，确保每一个重大变更都经过充分讨论和社区共识。

Future Work

Skill 市场与用户自定义 Skill、代码仓库解析与代码问答 Skill、图像/视频多模态 embedding 与画面级检索、faster-whisper 等本地 ASR 引擎接入、PaddleOCR/EasyOCR 等更多 OCR provider、Qdrant 等外部向量数据库后端、Ollama 本地模型一键配置、Agent 编排增强（反思、工具调用、失败恢复与任务规划纳入统一 DAG）。
