Agentic RAG System

MindDock

面向个人知识库的 Agentic RAG 系统

基于 LangGraph 编排的知识问答系统，支持意图自动感知、检索质量反思与有界重试、source-scoped 对比规划，以及完整的工作流可观测性。

Core Features

核心功能

六大核心能力，构建智能知识问答闭环

意图感知层

规则关键词匹配，自动识别 Chat / Summarize / Compare 三类任务，置信度分三档：0.9 / 0.65 / 0.5，低置信度走默认 Chat 路由。

IntentClassifier

LangGraph 检索编排

有向图工作流：retrieve → rerank → compress → quality_check，条件边支持分支路由，stream 接口逐节点输出事件流。

LangGraph DAG

反思层 / Bounded Retry

quality_check 节点判断证据质量，不足时触发 query_expand 扩展查询，max_retries=1 防止无限循环，兼顾效果与效率。

max_retries=1

Source-scoped Compare 规划

对两个指定来源分别独立检索压缩，left / right evidence 严格归属对应文档，避免证据交叉污染。

Source-scoped

LLM-backed 结构化对比

输出 common_points / differences / conflicts，每个对比点附带 left_evidence + right_evidence，JSON 解析失败时自动回退启发式对比。

Structured Compare

工作流可观测性

workflow_trace 记录意图、重试次数、质量判断、引用数，前端实时展示每个节点的决策依据与执行状态。

workflow_trace

Limitations & Future Work

局限性与未来方向

坦诚面对不足，持续迭代改进

⚠ 已知局限

  • ▸ 意图识别基于规则关键词匹配，无法处理隐式意图或复杂语义理解
  • ▸ 仅支持两来源对比，暂不支持多来源并行对比分析
  • ▸ 证据粒度为 chunk 级别，无法精确到句子或段落级别
  • ▸ 本地部署方案，无云端服务支持，扩展性受限
